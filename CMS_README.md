# DivyangSathi Website CMS

1. Run `CMS_SETUP.sql` once in Supabase SQL Editor.
2. Login as an active admin.
3. Open **Website CMS** (first sidebar item).
4. Use Page Content Editor to publish selector-based live changes.
5. Notifications support full-screen photo popups.
6. Deleted CMS content goes to Recycle Bin.

Core auth/profile/chat/membership source code is intentionally protected from CMS editing.
