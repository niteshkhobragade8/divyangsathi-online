DIVYANGSATHI FULL WEBSITE CMS V2

IMPORTANT DATABASE STEP
- If CMS_SETUP.sql was already run earlier, run CMS_V2_UPGRADE.sql once.
- For a completely fresh Supabase project, run CMS_SETUP_FINAL.sql once.

V2 FEATURES
- Pages Manager: automatic page/element dropdowns; no CSS selector typing.
- Page operations: text/HTML/image/link/placeholder/colors, hide/show, remove, add section before/after/inside, move/reorder after another selected element.
- Menu Manager: header/footer, page destination dropdown, icons, visibility/order, edit/delete.
- Theme Manager: presets, font, colors, radius, button styles, optional background upload, live publish.
- SEO Manager: page dropdown, title/meta/keywords/canonical/indexing, direct OG image upload.
- Notification Manager: normal/banner/popup/full-page, page + audience targeting, logo upload, banner/photo upload, CTA, schedule, priority, preview/edit/delete/publish.
- Media Library: direct file upload to Supabase Storage, preview/open/delete.
- Services/Categories: CRUD, direct image upload, order/status; active services render on Home when present.
- Documents: direct file upload, category/status, open/edit/delete; published documents render on Contact when present.
- CMS Analytics: CMS counts plus last-7-day page views and notification views/clicks.
- Recycle Bin: restore / delete forever.
- Revision History: automatic previous-version snapshots + restore.
- Global Settings: website name, support details, maintenance mode, announcement, direct logo/favicon upload.
- Public runtime: live theme/content/menu/SEO/settings/services/documents/notifications.

PROTECTED CORE
Login/auth, profile, chat, memberships and Supabase security logic are not exposed for visual CMS editing.
